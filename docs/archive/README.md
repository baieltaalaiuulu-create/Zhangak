# Архив документации Zhangak

Здесь хранятся завершённые handoff-промпты, исторические migration-планы и
выведенные из эксплуатации контракты. Архив сохраняет контекст решений, но не
является инструкцией для разработки или production.

## Правила

- Начинайте с `docs/README.md` и `docs/development/AI_AGENT_HANDOFF.md`.
- Любые числа, SHA, маршруты и схемы из архива перепроверяйте по текущему коду.
- Архивный Supabase-контракт нельзя использовать для возврата Supabase runtime.
- Секреты и PII не должны попадать в архив.
- Новый документ перемещается сюда, когда его задача завершена или его заменил
  канонический документ; в active index должна остаться ссылка только при
  реальной исторической необходимости.

## Разделы

- `agent-handoffs/` — завершённые промпты и отчёты отдельных AI-сессий.
- `content/` — заменённые версии инструкций импорта.
- `supabase/` — исторический контракт и план миграции с выведенного сервиса.
