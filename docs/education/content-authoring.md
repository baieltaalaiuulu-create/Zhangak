# Подготовка учебного контента

Документ для методиста, автора вопроса и администратора, который публикует
контент. Предметы v1: математика и кыргызский язык.

## Иерархия контента

```text
Курс (online или offline)
  └─ Урок
      ├─ Rich text / LaTeX
      ├─ PDF / изображение
      ├─ YouTube-видео
      └─ Тест
          └─ Вопрос: 4 варианта + 1 правильный ответ
```

Online и offline — разные курсы и интерфейсы. Один ученик не должен иметь два
текущих активных зачисления.

## Какие данные подготовить

### Курс

- понятное название;
- уникальный технический code латиницей;
- формат `online` или `offline`;
- предмет, уровень и описание результата обучения;
- обложка с подтверждённым правом использования;
- владелец курса и дата последней методической проверки.

### Урок

- последовательный номер;
- название, раздел, тема и предмет;
- учебная цель и краткое описание;
- примерная длительность;
- материалы в порядке показа;
- тест после урока, если он нужен для завершения.

Последовательность online-уроков контролирует backend. Урок без активного
теста ученик подтверждает сам; урок с опубликованным непустым тестом считается
завершённым только после серверно проверенной попытки.

### Материалы

| Тип | Требование |
| --- | --- |
| Текст | короткие блоки, заголовки, примеры, LaTeX для формул |
| PDF | до 200 MiB, права подтверждены, приватное хранение |
| Изображение | до 30 MiB, читаемая подпись/alt, без ответов в имени файла |
| Видео | Прямая HTTPS-ссылка на одно видео YouTube: `watch?v=`, `youtu.be/` или `/embed/`. Playlist, Shorts, live и ссылка на канал будут отклонены. Проверьте доступ и содержание |

Файл публикуется только после проверки типа, размера и scan-status. Не
используйте публичную ссылку на личный Google Drive как постоянное хранилище.

### Вопрос

- предмет: math или kyr;
- раздел, тема и сложность;
- однозначный текст;
- ровно четыре варианта `a–d`;
- ровно один правильный вариант;
- объяснение решения;
- изображение при необходимости;
- статус черновика до проверки.

AI может подготовить только черновик. Admin/super-admin обязан проверить факт,
язык, формулу, варианты, правильный ответ и объяснение до публикации.

## Редакционный процесс

1. Автор создаёт черновик и прикрепляет первоисточник/основание.
2. Методист проверяет содержание и соответствие программе.
3. Редактор проверяет язык, LaTeX, изображения и мобильное отображение.
4. Admin создаёт курс/урок/тест в неопубликованном состоянии.
5. Второй человек проходит тестовым учеником.
6. После исправлений admin публикует материал.
7. Через сутки проверяется реальный путь и обращения пользователей.

## Чек-лист вопроса

- [ ] Условие понятно без скрытого контекста.
- [ ] Есть четыре различающихся варианта.
- [ ] Только один вариант правильный.
- [ ] Правильный ответ совпадает с объяснением.
- [ ] Формулы корректно рендерятся на телефоне.
- [ ] Нет персональных данных и чужого защищённого текста.
- [ ] Изображение читаемо и имеет право на использование.
- [ ] Предмет, раздел, тема и сложность классифицированы.
- [ ] Черновик проверен человеком до публикации.

## Обновление контента

| Событие | Действие |
| --- | --- |
| Ошибка в вопросе | снять/деактивировать вопрос, исправить, повторно проверить |
| Изменилась программа ОРТ/ЖРТ | указать новый учебный год, сверить весь связанный раздел |
| Истёк доступ к видео | заменить ссылку и проверить урок учеником |

Видео открывается только внутри кабинета ученика с активным зачислением на
разблокированном уроке. Не обещайте ученикам, что видео нельзя скачать или
что ссылка полностью скрыта: точные формулировки и границы описаны в
[Видео уроков](../operations/lesson-video.md).
| Новый PDF | проверить право, версию, размер, scan-status и порядок |
| Жалоба ученика | сохранить ID вопроса/урока и описание без копирования персональных данных |

История результатов не исправляется ручным SQL после изменения вопроса:
попытка хранит снимок контента на момент прохождения.

Подробный production-процесс находится в
[регламенте контента](../operations/content-and-data.md).
