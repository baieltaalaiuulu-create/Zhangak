# Импорт учебных материалов

Этот процесс переносит проверенные материалы из локального архива `sorted_data`
в **собственный PostgreSQL и private storage Zhangak**. Supabase, публичные
Google Drive-ссылки и автоматическая публикация не используются.

## Этап 1: локальный манифест

До извлечения текста создайте воспроизводимый инвентарь файлов:

```bash
node backend/scripts/build-sorted-data-manifest.js \
  --input sorted_data \
  --output sorted_data/00_documentation_and_indexes/CONTENT_MANIFEST.json
```

Команда читает архив и создаёт JSON только внутри него. Она записывает
относительный путь, размер, SHA-256, предполагаемый предмет, целевую очередь и
флаги проверки. Существующий манифест не перезаписывается без `--overwrite`.

Скрипт не подключается к БД, не отправляет файлы в сеть, не вызывает AI и не
создаёт курсы, уроки или вопросы.

## Очереди проверки

| Источник | Очередь | Что делает человек |
| --- | --- | --- |
| `01_mathematics` | Материал/источник вопроса, `math` | Проверяет тему, право, формулы и место в уроке. |
| `02_kyrgyz_language` | Материал/источник вопроса, `kyr` | Проверяет язык, тему и методическую корректность. |
| `03_analogies` | Требует назначения предмета | Нельзя автоматически отнести к математике или кыргызскому языку. |
| `04_jrt_tsoomo_full_tests`, `05_tasks_and_practice` | Источник черновиков вопросов | Извлекает только после проверки автора, вариантов и ключа. |
| `06_chat_exports_and_history` | Заблокировано | Архив чатов не импортируется и не передаётся AI: возможны персональные данные и ключи. |
| `07_photo_archives` | Изображение после проверки | Нужны право, контекст задания и читаемость на телефоне. |

Каждый материал требует подтверждения прав. Все вопросы — ручной проверки
методистом или admin/super-admin до публикации.

## Целевые сущности Zhangak

- PDF и изображения после review: `lesson_materials` + private filesystem;
- текст и YouTube-ссылки: `lesson_materials`;
- тест: `practice_tests`;
- вопрос с ровно четырьмя вариантами: `practice_questions`;
- прогресс и ответы учеников: только серверные попытки, не импортируются из
  raw-материалов.

Не существует таблиц `quizzes`, `question_options`, `course_materials` или
`private_materials` в текущем контракте. Их нельзя использовать в новом коде.

## Следующий этап: импорт черновиков

Следующий скрипт появится только после review манифеста. Он обязан:

1. принимать конкретный утверждённый список SHA-256, а не всю папку;
2. создавать только `draft`-материалы/вопросы;
3. отклонять ответ вне `a`–`d`, дубли, отсутствующий источник и неясный
   предмет;
4. сохранять source path, checksum и audit event;
5. запускаться dry-run по умолчанию, а запись включать отдельным `--apply`;
6. не читать и не импортировать Telegram-архивы.

Полный порядок публикации находится в
[руководстве автора контента](../education/content-authoring.md).
