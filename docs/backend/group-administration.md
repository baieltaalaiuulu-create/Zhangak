# Управление учебными группами

Группы и назначения используют существующий первый срез схемы
`002_learning_core.sql`: таблицы `groups` и `group_students`. Отдельная
миграция для административного интерфейса не нужна.

## Доступ

Все маршруты ниже требуют собственную HttpOnly-сессию Zhangak и роль `admin`
или `super_admin`. Маршруты не вызывают Supabase и не принимают id автора,
роль пользователя или произвольные поля из клиента.

## API

| Действие | Маршрут |
| --- | --- |
| Список и карточка группы | `GET /v1/admin/groups`, `GET /v1/admin/groups/:groupId` |
| Создание / настройка | `POST /v1/admin/groups`, `PATCH /v1/admin/groups/:groupId` |
| Состав группы | `GET /v1/admin/groups/:groupId/members` |
| Каталог активных кандидатов | `GET /v1/admin/group-assignees?kind=teacher|student` |
| Назначение / снятие преподавателя | `PATCH /v1/admin/groups/:groupId/teacher` (`teacherId` или `null`) |
| Добавление ученика | `POST /v1/admin/groups/:groupId/students` |
| Исключение ученика | `DELETE /v1/admin/groups/:groupId/students/:studentId` |

## Инварианты

- группа всегда принадлежит уже существующему активному курсу; её курс нельзя
  сменить при редактировании;
- назначенным преподавателем может быть только незаблокированный пользователь
  с ролью `teacher`;
- учеником может быть только незаблокированный пользователь с ролью `student`;
- формат группы и тип обучения проверяются сервером: `online` допускает
  `online`/`both`, `offline` — `offline`/`both`, `hybrid` — только `both`;
- при указанной вместимости сервер не допускает переполнение и не позволяет
  снизить вместимость ниже текущего состава;
- при смене формата сервер откажет, пока состав несовместим с новым форматом;
- удаление ученика не удаляет запись: `left_at` фиксирует дату ухода и
  сохраняет учебную историю;
- создание, изменение группы, назначение/снятие преподавателя и добавление/
  исключение ученика попадают в `audit_log`.

Текущий UI: `/admin/groups`. Учёт посещаемости, домашней работы и оценок не
является частью этой модели и остаётся отдельным будущим срезом схемы.
