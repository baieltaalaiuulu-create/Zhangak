# Офлайн-группа: ежедневная работа

Этот регламент относится к `offline.zhangak.com`. Оффлайн-курс не смешивается
с online-курсом: у ученика один активный формат и один текущий курс.

## Кто что делает

| Роль | Действия |
| --- | --- |
| Admin / super-admin | Создаёт курс и группу, назначает преподавателя, добавляет/исключает учеников, задаёт расписание, публикует объявления. |
| Преподаватель | Только в своих назначенных группах отмечает посещаемость, создаёт домашние задания, выставляет оценки 0–100 и пишет комментарии. |
| Ученик | Видит своё расписание, посещаемость, опубликованные оценки, домашние задания, видимые комментарии и объявления; сдаёт текст домашней работы. |

Преподаватель не может менять учётные записи, курс, состав группы, расписание
или объявления. Внутренний комментарий видит только команда; ученик его не
получает. Все изменения журналируются в `audit_log`.

## Настройка перед первым занятием

1. В `admin.zhangak.com` → «Уроки» создайте и опубликуйте уроки офлайн-курса.
2. В «Группы» создайте офлайн-группу, назначьте преподавателя и добавьте
   только активных офлайн-учеников.
3. В карточке группы откройте «Расписание и объявления», выберите урок,
   дату, время и кабинет. Именно это занятие становится основанием для
   посещаемости и оценки за урок.
4. При необходимости опубликуйте объявление: его увидят только ученики этой
   группы в своём кабинете.
5. Проверьте путь тестовым учеником на `offline.zhangak.com`.

## Журнал преподавателя

После занятия преподаватель открывает только назначенную ему группу и:

1. выбирает занятие и сохраняет посещаемость каждого ученика: «был»,
   «опоздал» или «отсутствовал»;
2. создаёт домашнее задание. Если срок не задан, сервер устанавливает начало
   следующего запланированного занятия; преподаватель может выбрать другой
   срок;
3. выставляет оценку от 0 до 100 и решает, публиковать ли её ученику;
4. при необходимости добавляет комментарий: видимый ученику либо внутренний
   для команды.

Не используйте имя/балл ученика из адресной строки или DevTools: сервер сам
проверяет назначение преподавателя и активное членство ученика в группе.

## Ограничения v1

- Домашняя работа сдаётся текстом. Вложения к домашним работам появятся после
  отдельного безопасного потока файлового хранения.
- Оценка за урок и за домашнюю работу обновляется как одна запись для пары
  «ученик + источник». Это предотвращает случайное дублирование оценки.
- Черновое объявление не показывается ученикам; в списке администратора оно
  помечено «Черновик».
